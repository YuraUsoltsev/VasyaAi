# 🤖 Vasya Ai v3.0 — Умный чат-бот нового поколения

**Vasya Ai** — это не просто бот, это твой личный ИИ-помощник, который узнает тебя, помнит твои данные и решает проблемы как настоящий ChatGPT, но в терминале.

## ✨ Новые возможности v3.0

### 🔐 Регистрация пользователя
Перед началом общения бот запросит:
- **Имя** — как к тебе обращаться
- **Фамилия** — для полного профиля
- **Возраст** — для адаптации стиля советов
- **Знак зодиака** — для психологического портрета и персонализации ответов

### 🧠 Интеллектуальный анализ
- Определяет категорию проблемы (код, жизнь, наука, творчество)
- Учитывает твой возраст и знак зодиака при формировании ответа
- Запоминает контекст беседы (последние 10 сообщений)
- Адаптирует стиль общения под твою личность

### 💾 Постоянная память
- Профиль сохраняется в файле `user_data.json`
- При следующем запуске бот сразу узнает тебя
- Команда `анкета` покажет все сохраненные данные

## 📁 Структура проекта

## 🚀 Как запустить

### Вариант 1: В Visual Studio 2019 / VS Code
1. Откройте папку `/workspace` в редакторе
2. Откройте файл `VasyaAi.py`
3. Нажмите **F5** или кнопку **Run**
4. В терминале введите свои данные при первом запуске

### Вариант 2: Через терминал Windows 11
```cmd
cd C:\путь\к\папке\VasyaAi
python VasyaAi.py
```

Или откройте терминал прямо в папке с файлом:
1. Зажмите **Shift** и кликните правой кнопкой мыши в папке
2. Выберите **"Открыть окно PowerShell здесь"** или **"Открыть в Терминале"**
3. Выполните: `python VasyaAi.py`

### Вариант 3: Linux / macOS
```bash
cd /workspace
python3 VasyaAi.py
```

## 💬 Команды бота

| Команда | Описание |
|---------|----------|
| `помощь` | Показать список всех команд |
| `анкета` | Показать ваши сохраненные данные |
| `контекст` | Показать текущий контекст беседы |
| `сброс` | Очистить историю переписки |
| `пока` / `выход` | Завершить работу бота |

## 🎯 Почему Vasya Ai особенный?

1. **Персонализация** — использует имя, возраст и знак зодиака
2. **Глубина ответов** — не просто "да/нет", а развернутые советы
3. **Память** — помнит вас между сессиями
4. **Эмпатия** — распознает эмоции и поддерживает
5. **Простота** — работает в любом терминале без интернета
