# Vasya Ai - Умный чат-бот для решения любых проблем

## Описание
**Vasya Ai** — это интеллектуальный чат-бот с модульной архитектурой, способный решать различные проблемы пользователя: от программирования до жизненных ситуаций.

## Особенности версии 2.0
- 🧠 **Умный анализ запросов** — определяет категорию проблемы и эмоции пользователя
- 📚 **Расширенная база знаний** — подробные ответы по категориям: код, учёба, жизнь, технологии
- 💾 **Сохранение истории** — контекст диалога сохраняется между сессиями
- 👤 **Персонализация** — запоминает имя пользователя и обращается по имени
- 🔍 **Глубокий анализ** — учитывает срочность, детализацию и эмоциональный тон
- 💡 **Дополнительные советы** — даёт развёрнутые рекомендации с примерами кода

## Запуск в Visual Studio 2019

### Способ 1: Через IDE
1. Откройте Visual Studio 2019
2. **Файл → Открыть → Файл**
3. Выберите `/workspace/VasyaAi.py`
4. Убедитесь, что Python установлен (Проверка: **Вид → Другие окна → Интерактивное окно Python**)
5. Нажмите **F5** или кнопку **Run** (зелёная стрелка)
6. Или: ПКМ по файлу → **Запустить с помощью Python**

### Способ 2: Через терминал
```bash
cd /workspace
python VasyaAi.py
```

## Команды бота
| Команда | Описание |
|---------|----------|
| `помощь` | Показать справку по командам |
| `история` | Показать историю переписки |
| `очистить` | Очистить историю диалога |
| `контекст` | Показать текущий контекст ИИ |
| `темы` | Показать обсуждаемые темы |
| `пока` / `выход` | Завершить работу |

## Технические детали

### Модуль knowledge_base.py
Содержит базу знаний с ответами по категориям и функцию определения категории по ключевым словам.

### Модуль context_manager.py
Класс `ConversationContext` управляет:
- Историей диалога (сохранение в JSON)
- Именем пользователя
- Эмоциональным состоянием
- Тематикой обсуждений

### Модуль ai_engine.py
Класс `VasyaAiEngine` выполняет:
- Глубокий анализ сообщений
- Определение эмоций и срочности
- Генерацию персонализированных ответов
- Обработку специальных команд

## Требования
- Python 3.6+
- Стандартные библиотеки: `json`, `datetime`, `re`, `random`
